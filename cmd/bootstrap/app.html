Demo Room

One double-click app per OS in dist/demo (Linux + Windows): the five demo shops, each with a year of trade, every plugin. Opening a shop moves its year up to today, so a build stays fresh for as long as you keep it.
Each shop's year takes minutes to build, so it's kept and reused until something that shapes the data changes (the database, the services, the shops). Then it's about a minute.
POS_SUPPORT_SECRET isn't set — the Demo Room's lock needs it (set it in .env).
