# Karots Suite guides

Plain-English guides with screenshots from the Demo Room's **Karots Super Store**, a shop with
every plugin and a year of trade behind it. The screenshots are retaken with `make docs-shots`
whenever the screens change.

| [Stock](stock.md) | Products, categories, packs, batches and expiry, intake, stock-take, conversions, smart reorder levels |
| [Purchasing](purchasing.md) | Suppliers, purchase orders, receiving and GRNs, reorder, returns to suppliers |
| [Money](money.md) | Opening and closing the till, lockers, expenses, cash flow, finance, receipts |

| [Printing](printing.md) | Receipts (Classic or Image), the ten receipt styles, labels, ask before printing |
| [Appearance](appearance.md) | Palettes, your own palettes, light and dark |
| [Plugins](plugins/README.md) | One page for each of the ten plugins |
