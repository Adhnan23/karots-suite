# Plugins

A shop gets only the plugins it needs. Each one is compiled into that shop's program by the [Shop Builder](../install.md). A plugin adds its own pages, till buttons, receipt slips, labels and reports, and the core works the same without it.

| Plugin | |
|---|---|
| [Reload & Bills](recharge.md) | For a shop that is a mobile-money agent: reloads, carrier packages, bill payments, wallet deposits and cash outs. |
| [Pharmacy](pharmacy.md) | Patients, prescriptions and the controlled-drug register for a pharmacy. |
| [Repairs](repairs.md) | Repair jobs from drop-off to pickup. |
| [Print & Copy](documents.md) | Photocopy, print, laminate and bind, for a shop with a copier. |
| [Alternatives](alternatives.md) | Group products that can stand in for each other, such as two brands of the same medicine or two qualities of a cable. |
| [Clearance](clearance.md) | Mark down slow and expiring stock before it becomes a loss. |
| [AI Assistant](aicatalog.md) | Catalogue help for whoever sets the shop up. |
| [Product Plus](productplus.md) | Extra product fields for the things your shop cares about: brand, generic name, manufacturer, guarantee, fits… |
| [Combos](combos.md) | Product deals: a group of products, or one product in bulk such as buy 3 get 1 free. |
| [Customer requests](requests.md) | Remember what customers ask for that the shop doesn't carry. |

A plugin's records are part of the shop's backup and come back with it.
