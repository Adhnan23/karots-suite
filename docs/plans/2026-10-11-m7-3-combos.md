# M7.3 Combos — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.
> Same shape as M7.2. Opus executes and reviews, one commit per step, and UI gates are self-reviewed (4 combos, 1366 + 360).

**Goal:** Combos, reinterpreted. Deals ring as real discounted lines that add up to the cent (retail or
wholesale), stay together in the cart, are spotted by the till when the members are scanned one by one,
run between dates, flag broken members, and are counted in a Combos report.

**Spec:** `docs/specs/2026-10-11-m7-3-combos-design.md`. Fork source: karots-pos `plugins/combos/` (read-only;
Task 10 is a bug-fix commit there).

## Global constraints

- **Core never references a plugin and never changes for one plugin.** The core changes are the generic
  seams in spec §3 (Tasks 3–4). `make check-core` must pass after every task.
- `enabled_plugins.go` / `enabled-plugins.ts` are committed **core-only** (`make plugins P=combos` to work,
  `make core-only` before committing).
- The plugin's JSON types live in `plugins/combos/api.go`, mirrored by hand in `web/src/plugins/combos/types.ts`.
- Errors through `apperr`, camelCase JSON, money as decimal strings, files ≤ 500 lines.
- Theme tokens only, 360px for admin and report, 4 combos (Studio / Night × light / dark).
- No Claude / AI attribution in commits.

## Review focus

1. **Exact money.** For every type, retail and wholesale, the combo's lines sum to exactly the set's
   discount × count, never more than the full price (Task 5).
2. **Groups.** A scan never merges into a combo line; ± scales every line; break returns the rest to full
   price; hold / resume and reload keep the group (Task 3).
3. **Hint Apply** moves units from plain lines into the group without changing the cart's item counts
   (Task 5 matcher + Task 7).
4. **A karots-pos backup** with `combos` / `combo_items` restores unchanged and every old combo is on
   (Task 9).
5. **Cashier on admin routes** gets 403; `/sold` refuses an unknown sale (Task 2).
