> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** one product counted in its smallest unit (tablet) can be sold, bought and scanned by the pack (Card ×12),
with full packs priced at the pack price automatically — no loose twin products.

**Spec:** `docs/specs/2026-10-14-m7-7a-packs-design.md`. Code to read first: `internal/features/sales/service_lines.go`
(line pricing), `internal/features/products/barcodes.go` + `migrations/00003_product_barcodes.sql`, `internal/api/till*.go`
(TillProduct, barcode lookup), `web/src/features/till/cart/{types,lines,totals,store}.ts`, `cart-ui/CartLineRow.tsx`,
`catalog/useAddProduct.ts`, `catalog/useEntry.ts`, `internal/escpos/items.go`, `internal/features/purchases/service_create.go`
(`parseLines`), `web/src/features/purchasing/LineEditor.tsx`, `web/src/features/admin/intake/IntakePage.tsx`,
`web/src/features/admin/products/{BarcodesBlock,LooseVersion,ReviewPage}.tsx`.

## Global constraints

- Core never names a plugin; `make check-core` after every task. Plugin lists committed core-only.
- DTOs in the matching `internal/api/dto_*.go` → `make types`; never hand-edit `types.gen.ts`.
- Quantities everywhere stay in the product's unit; a pack only changes price (sales), entry (purchases / intake) and
  display. `stock.quantity` = SUM(batches) after every write.
- Money: line subtotal = exact packed gross − discount; a pack never raises a line. Go `PackGross` and TS `lineGross`
  share one table test.
- A question to the cashier is a prompt/dialog, never a toast. Never stop a sale.
- Theme tokens only, admin works at 360px, 4 combos. Files ≤ 500 lines. No AI attribution in commits.
- The :3100 demo may be running for the user — test servers on :3101.

## Review focus

1. Same table, same answer: `PackGross` (Go) and `lineGross` (TS) — Tasks 2, 4.
2. A part return of a pack-priced line refunds what was paid, to the cent — Task 2.
3. Purchase by the card: payable = qty × card cost exactly; stock / batch in units; lot cost = paid ÷ units — Task 7.
4. Fold: card stock fully converted (expiry kept), barcodes now add a card at the till, nothing half-done on error — Task 8.
5. A product without packs behaves exactly as before everywhere (cart, receipt, purchase) — every task.
