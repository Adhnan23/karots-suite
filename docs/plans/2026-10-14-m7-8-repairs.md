## Global constraints

- Core never names a plugin; `make check-core` after every task; plugin lists committed core-only.
- Repairs writes only `repair_*`; money only via core services (`cashflow.MoveTx`, expenses, sales).
- Never stop a sale: the deposit pre-fill and hints never block Pay.
- karots-pos migrations 0001–0005 byte for byte; an old repairs backup restores without mapping.
- Theme tokens only; admin works at 360px; files ≤ 500 lines; no AI attribution.

## Review focus

1. Pre-filled On account never exceeds the customer's advance or the bill; legacy deposit tender can't overdraw — Tasks 1, 3.
2. After-sale marks only the tagged job, once; hold / New sale leave it open — Task 4.
3. Cancel with a deposit offers the refund (advance or legacy cash) — Tasks 3, 4; karots-pos fix.
4. Old karots-pos repairs data restores and shows (jobs, lines, legacy deposits, paid) — Task 2.
