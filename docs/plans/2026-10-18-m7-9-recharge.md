# M7.9 Reload & Bills (recharge) — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.
> Opus executes and reviews, one commit per step, UI gates self-reviewed (4 combos, till 1366, admin 360 + 1366).

**Goal:** reloads, packages, bills, wallet deposits and cash outs as cart lines on the normal Pay; one running
float per device with commission booked as it happens; counts as checks; buying float is not an expense.

**Spec:** `docs/specs/2026-10-18-m7-9-recharge-design.md`. Read first: karots-pos `plugins/recharge` (Go, templ,
`static/bill_cash.js`, migrations 00001–00019), its memory notes `recharge-passthrough-pl.md`,
`recharge-device-credit-billpay.md`, `admin-bill-pay-cash.md`, `reload-supplier-refill-ux.md`,
`till-open-close-side-by-side-float.md`; suite `plugins/repairs` (layout, line hook, tender, restore test,
web index), `internal/features/sales/service.go` (totals, tenders, line hook), `service_returns.go`,
`customers/payments.go`, `web/src/features/till/pay/`, `cart/store.ts`, `counter/credit/CreditForm.tsx`.

## Global constraints

- Core never names a plugin; `make check-core` after every task; plugin lists committed core-only.
- Recharge writes only `recharge_*` (+ its own products through core services); money only via core
  (`cashflow.MoveTx`, sales, returns, customer payments).
- Never stop a sale: no float / bank refusal anywhere at the till.
- karots-pos migrations 00001–00019 byte for byte; an old recharge backup restores and its balances match.
- Theme tokens only; admin works at 360px; files ≤ 500 lines; no AI attribution.

## Review focus

1. Payout lines: a negative total only through payout lines, cash only, drawer expected right, no return /
   discount of a payout — Task 1.
2. Every float move and its commission row commit in the same tx as the sale / return / payment — Tasks 4, 5.
3. Restored karots-pos balances equal its `DeviceBalances()`; old earnings and the refill add-back — Task 3.
4. Refill books no expense; P&L earnings = commission + count differences — Tasks 5, 8.
